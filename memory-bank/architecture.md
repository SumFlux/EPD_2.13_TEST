# 项目架构文档

> 最后更新: 2026-02-02

## 项目概述

本项目是 ESP32-S3 驱动 2.13 寸 IL3897 墨水屏的测试工程，支持编码器交互控制。

## 目录结构

```

│   ├── src/
│   │   └── main.cpp             # 主程序（V1.0.0.2）
│   ├── platformio.ini           # PlatformIO 配置
│   └── .pio/                    # 编译输出
├── doc/
```

## 核心模块

### 1. 墨水屏驱动 (`main.cpp`)

| 模块 | 功能 |
|------|------|
| **显示初始化** | SPI 配置、GxEPD2 初始化 |
| **局部刷新** | `setPartialWindow()` + 分页绘制 |
| **对比度恢复** | 全屏黑白刷新，消除残影 |
| **版本显示** | 右下角常驻版本号 |

### 2. 编码器控制

| 功能 | 实现 |
|------|------|
| **旋转检测** | 中断 + 状态机，4步=1格 |
| **按键检测** | 中断 + 300ms 防抖 |
| **刷新节流** | 200ms 最小刷新间隔 |

### 3. 刷新策略

```
普通局刷 → 每3次闪白 → 每20次深度恢复
```

## 依赖库

- `GxEPD2@^1.6.6` - 墨水屏驱动库
- `Adafruit GFX Library@^1.12.1` - 图形库

## 技术要点

1. **避免全刷闪烁**：使用 `setPartialWindow(0,0,250,122)` 替代 `setFullWindow()`
2. **编码器防抖**：累积4步才触发1次变化
3. **局刷残影**：定期执行黑白刷新恢复对比度
