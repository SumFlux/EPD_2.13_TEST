## 1. 基础系统工具安装

首先更新系统软件包列表，并安装必要的编译工具和实用程序。

```bash
# 更新软件源
sudo apt update && sudo apt upgrade -y

# 安装基础工具
# build-essential: 编译 C/C++ 扩展所必需 (解决 sxtwl 等库的安装问题)
# curl, wget: 下载工具
# git: 代码版本管理
# vim: 文本编辑器
# supervisor: 进程守护 (用于生产环境后台运行)
sudo apt install -y build-essential curl wget git vim supervisor
```

## 2. Python 环境配置

项目依赖 **Python 3.10+**。Ubuntu 22.04 默认自带 Python 3.10，可以直接使用。

### 检查 Python 版本
```bash
python3 --version
# 输出应 >= 3.10.x
```

### 安装 Python 开发包和 pip
为了编译部分依赖库（如 `sxtwl`），必须安装 python3-dev。

```bash
sudo apt install -y python3-dev python3-pip python3-venv
```

## 3. 数据库环境 (MySQL 8.0)

### 安装 MySQL
```bash
sudo apt install -y mysql-server
```

### 安全配置
运行安全脚本，设置 root 密码并移除不安全的默认设置。
```bash
sudo mysql_secure_installation
```
按照提示操作：
1. VALIDATE PASSWORD COMPONENT? -> N (开发环境选 N，生产环境建议 Y)
2. New password -> 设置您的 root 密码
3. Remove anonymous users? -> Y
4. Disallow root login remotely? -> Y (建议 Y，为了安全)
5. Remove test database? -> Y
6. Reload privilege tables now? -> Y

### 创建项目数据库和用户
登录 MySQL 控制台：
```bash
sudo mysql -u root -p
```

在 MySQL 提示符下执行：
```sql
-- 创建数据库
CREATE DATABASE infinity_tag CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;

-- 创建用户 (请将 your_password 替换为强密码)
CREATE USER 'infinitytag'@'localhost' IDENTIFIED BY 'your_password';

-- 授权
GRANT ALL PRIVILEGES ON infinity_tag.* TO 'infinitytag'@'localhost';

-- 刷新权限
FLUSH PRIVILEGES;
EXIT;
```

## 4. 缓存环境 (Redis)

### 安装 Redis
```bash
sudo apt install -y redis-server
```

### 配置 Redis (可选)
编辑配置文件：
```bash
sudo vim /etc/redis/redis.conf
```
- 修改 `supervised no` 为 `supervised systemd`
- 如果需要密码，找到 `# requirepass foobared`，去掉注释并修改密码

### 启动 Redis
```bash
sudo systemctl restart redis.service
sudo systemctl enable redis.service
```

## 5. 项目部署步骤

### 5.1 克隆代码
```bash
# 创建项目目录
mkdir -p /var/www/infinity-tag
cd /var/www/infinity-tag

# 克隆代码 (建议使用 SSH key 或 HTTPS token)
git clone https://github.com/your-repo/infinity-tag-backend.git .
```

### 5.2 创建虚拟环境并安装依赖
```bash
# 创建虚拟环境
python3 -m venv venv

# 激活环境
source venv/bin/activate

# 安装依赖
pip install --upgrade pip
pip install -r requirements.txt
```
> **注意**: 如果遇到 `sxtwl` 安装失败，请确保已安装第一步中的 `build-essential` 和 `python3-dev`。

### 5.3 环境变量配置
```bash
cp .env.example .env
vim .env
```
修改以下关键配置：
- `MYSQL_PASSWORD`: 步骤 3 中设置的密码
- `JWT_SECRET_KEY`: 生成一个随机字符串 (运行 `openssl rand -hex 32`)
- `ENVIRONMENT`: 设置为 `production`

### 5.4 初始化数据库
```bash
# 应用数据库迁移
alembic upgrade head
```

### 5.5 启动服务
**开发测试运行**:
```bash
uvicorn app.main:app --host 0.0.0.0 --port 8000
```

**生产环境运行 (使用 Supervisor)**:
创建配置文件 `/etc/supervisor/conf.d/infinity-tag.conf`:
```ini
[program:infinity-tag]
directory=/var/www/infinity-tag
command=/var/www/infinity-tag/venv/bin/uvicorn app.main:app --host 127.0.0.1 --port 8000 --workers 4
user=www-data
autostart=true
autorestart=true
stderr_logfile=/var/log/infinity-tag.err.log
stdout_logfile=/var/log/infinity-tag.out.log
```
启动服务：
```bash
sudo supervisorctl reread
sudo supervisorctl update
sudo supervisorctl start infinity-tag
```

## 6. Docker 方式部署 (推荐)

如果您不想手动安装上述环境，可以直接使用 Docker。这是最简单的部署方式。

### 安装 Docker
```bash
# 卸载旧版本
sudo apt remove docker docker-engine docker.io containerd runc

# 安装依赖
sudo apt install -y ca-certificates curl gnupg lsb-release

# 添加 Docker GPG key
sudo mkdir -m 0755 -p /etc/apt/keyrings
curl -fsSL https://download.docker.com/linux/ubuntu/gpg | sudo gpg --dearmor -o /etc/apt/keyrings/docker.gpg

# 设置仓库
echo "deb [arch=$(dpkg --print-architecture) signed-by=/etc/apt/keyrings/docker.gpg] https://download.docker.com/linux/ubuntu \
  $(lsb_release -cs) stable" | sudo tee /etc/apt/sources.list.d/docker.list > /dev/null

# 安装 Docker Engine
sudo apt update
sudo apt install -y docker-ce docker-ce-cli containerd.io docker-buildx-plugin docker-compose-plugin
```

### 一键部署
```bash
# 在项目根目录下
docker compose up -d --build
```
此命令会自动拉取 MySQL 和 Redis 镜像，构建后端应用，并启动所有服务。

## 7. 常见问题

### Q: `pip install` 报错 `Failed building wheel for sxtwl`
**原因**: 缺少 C++ 编译环境或 Python 开发头文件。
**解决**:
```bash
sudo apt install build-essential python3-dev
```

### Q: MySQL 连接报错 `Access denied for user 'root'@'localhost'`
**原因**: MySQL 8.0 默认 root 使用 socket 认证，不允许密码登录。
**解决**: 使用专门创建的 `infinitytag` 用户，或者修改 root 认证方式（不推荐）。

### Q: 端口 8000 无法访问
**原因**: 云服务器防火墙（安全组）未开放端口。
**解决**: 登录云服务商控制台（阿里云/腾讯云/AWS），在安全组规则中添加入站规则：协议 TCP，端口 8000，源 0.0.0.0/0。
