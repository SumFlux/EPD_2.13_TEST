## 1. Windows 本地开发环境（推荐）

适用于本地开发和测试，支持热重载、断点调试。

### 1.1 安装 Python 3.10+

**下载安装包**:
- 访问 https://www.python.org/downloads/
- 下载 Python 3.10 或更高版本的 Windows 安装包

**安装时注意**:
- ✅ 勾选 "Add Python to PATH"
- ✅ 勾选 "Install pip"

**验证安装**:
```bash
python --version
# 输出: Python 3.10.x 或更高

pip --version
# 输出: pip 23.x.x
```

---

### 1.2 安装 Docker Desktop

**下载地址**: https://www.docker.com/products/docker-desktop/

**安装后启动 Docker Desktop**，确保左下角鲸鱼图标显示为绿色 (Running)。

**验证安装**:
```bash
docker --version
# 输出: Docker version 24.x.x

docker compose version
# 输出: Docker Compose version v2.x.x
```

---

### 1.3 克隆项目并安装依赖

```bash
# 克隆代码
git clone https://github.com/your-repo/infinity-tag-backend.git
cd infinity-tag-backend

# 创建虚拟环境
python -m venv venv

# 激活虚拟环境 (Windows)
venv\Scripts\activate

# 安装依赖
pip install --upgrade pip
pip install -r requirements.txt
```

**重要提示**:
- 如果遇到 `sxtwl` 或其他 C 扩展编译失败，请安装 **Microsoft C++ Build Tools**:
  - 下载地址: https://visualstudio.microsoft.com/visual-cpp-build-tools/
  - 安装时选择 "Desktop development with C++"

---

### 1.4 配置环境变量

```bash
# 复制环境变量模板
copy .env.example .env

# 使用记事本或 VS Code 编辑 .env
notepad .env
```

**关键配置项**（必须修改）:

| 变量 | 说明 | 示例值 |
|------|------|--------|
| `MYSQL_PASSWORD` | MySQL 数据库密码 | `infinitytag_password` |
| `MYSQL_ROOT_PASSWORD` | MySQL root 密码 | `root_password` |
| `JWT_SECRET_KEY` | JWT 签名密钥（生产环境务必替换） | 使用 `openssl rand -hex 32` 生成 |
| `AI_API_KEY` | AI 服务 API 密钥 | `sk-xxxxx` |

**开发环境建议配置**:
```env
DEBUG=True
ENVIRONMENT=development
FORCE_HTTPS=False
CORS_ORIGINS=["*"]
```

---

### 1.5 启动数据库服务

```bash
# 仅启动 MySQL 和 Redis (不启动后端容器)
docker compose up -d mysql redis

# 验证容器状态
docker compose ps
```

**首次启动**还需要运行数据库迁移:
```bash
# 确保虚拟环境已激活
alembic upgrade head
```

---

### 1.6 启动后端服务

```bash
# 开发模式（支持热重载）
uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
```

**看到以下输出说明启动成功**:
```
INFO:     Uvicorn running on http://0.0.0.0:8000 (Press CTRL+C to quit)
INFO:     Started reloader process [xxxxx] using WatchFiles
INFO:     Application startup complete.
[INFO] Infinity Tag Backend v1.0.0 启动成功！
[ENV] 环境: development
[DB]  数据库: localhost:3306/infinity_tag
```

**访问验证**:
- 健康检查: http://localhost:8000/health
- API 文档: http://localhost:8000/docs
- 静态资源: http://localhost:8000/assets/

## 2. Linux 服务器部署环境

适用于生产环境或 VPS 部署（以 Ubuntu 22.04 LTS 为例）。

### 2.1 基础系统工具安装

```bash
# 更新软件源
sudo apt update && sudo apt upgrade -y

# 安装基础工具
sudo apt install -y build-essential curl wget git vim supervisor
```

---

### 2.2 Python 环境配置

**检查 Python 版本**:
```bash
python3 --version
# 输出应 >= 3.10.x
```

**安装 Python 开发包**:
```bash
sudo apt install -y python3-dev python3-pip python3-venv
```

---

### 2.3 数据库环境 (MySQL 8.0)

**安装 MySQL**:
```bash
sudo apt install -y mysql-server
```

**安全配置**:
```bash
sudo mysql_secure_installation
```

按照提示操作:
1. VALIDATE PASSWORD COMPONENT? → N (开发环境选 N，生产环境建议 Y)
2. New password → 设置您的 root 密码
3. Remove anonymous users? → Y
4. Disallow root login remotely? → Y
5. Remove test database? → Y
6. Reload privilege tables now? → Y

**创建项目数据库和用户**:
```bash
sudo mysql -u root -p
```

在 MySQL 提示符下执行:
```sql
CREATE DATABASE infinity_tag CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
CREATE USER 'infinitytag'@'localhost' IDENTIFIED BY 'your_password';
GRANT ALL PRIVILEGES ON infinity_tag.* TO 'infinitytag'@'localhost';
FLUSH PRIVILEGES;
EXIT;
```

---

### 2.4 缓存环境 (Redis)

**安装 Redis**:
```bash
sudo apt install -y redis-server
```

**启动 Redis**:
```bash
sudo systemctl restart redis.service
sudo systemctl enable redis.service
```

---

### 2.5 项目部署步骤

**克隆代码**:
```bash
mkdir -p /var/www/infinity-tag
cd /var/www/infinity-tag
git clone https://github.com/your-repo/infinity-tag-backend.git .
```

**创建虚拟环境并安装依赖**:
```bash
python3 -m venv venv
source venv/bin/activate
pip install --upgrade pip
pip install -r requirements.txt
```

**环境变量配置**:
```bash
cp .env.example .env
vim .env
```

修改关键配置（同 Windows 章节）。

**初始化数据库**:
```bash
alembic upgrade head
```

**生产环境运行 (使用 Supervisor)**:

创建配置文件 `/etc/supervisor/conf.d/infinity-tag.conf`:
```ini
[program:infinity-tag]
directory=/var/www/infinity-tag
command=/var/www/infinity-tag/venv/bin/uvicorn app.main:app --host 127.0.0.1 --port 8000 --workers 4
user=www-data
autostart=true
autorestart=true
stderr_logfile=/var/log/infinity-tag.err.log
stdout_logfile=/var/log/infinity-tag.out.log
```

启动服务:
```bash
sudo supervisorctl reread
sudo supervisorctl update
sudo supervisorctl start infinity-tag
```

## 3. Docker 方式部署（推荐生产环境）

如果您不想手动安装上述环境，可以直接使用 Docker。这是最简单的部署方式。

### 3.1 安装 Docker (Ubuntu)

```bash
# 卸载旧版本
sudo apt remove docker docker-engine docker.io containerd runc

# 安装依赖
sudo apt install -y ca-certificates curl gnupg lsb-release

# 添加 Docker GPG key
sudo mkdir -m 0755 -p /etc/apt/keyrings
curl -fsSL https://download.docker.com/linux/ubuntu/gpg | sudo gpg --dearmor -o /etc/apt/keyrings/docker.gpg

# 设置仓库
echo "deb [arch=$(dpkg --print-architecture) signed-by=/etc/apt/keyrings/docker.gpg] https://download.docker.com/linux/ubuntu \
  $(lsb_release -cs) stable" | sudo tee /etc/apt/sources.list.d/docker.list > /dev/null

# 安装 Docker Engine
sudo apt update
sudo apt install -y docker-ce docker-ce-cli containerd.io docker-buildx-plugin docker-compose-plugin
```

---

### 3.2 一键部署

```bash
# 在项目根目录下
docker compose up -d --build
```

此命令会自动拉取 MySQL 和 Redis 镜像，构建后端应用，并启动所有服务。

**查看日志**:
```bash
docker compose logs -f backend
```

**停止服务**:
```bash
docker compose down
```

## 4. 常见问题

### Q1: `pip install` 报错 `Failed building wheel for sxtwl`

**原因**: 缺少 C++ 编译环境或 Python 开发头文件。

**解决 (Windows)**:
- 安装 Microsoft C++ Build Tools
- 下载地址: https://visualstudio.microsoft.com/visual-cpp-build-tools/

**解决 (Linux)**:
```bash
sudo apt install build-essential python3-dev
```

---

### Q2: MySQL 连接报错 `Can't connect to MySQL server`

**原因 (Windows)**: Docker 容器未启动或未正确映射端口。

**解决**:
```bash
# 检查容器状态
docker compose ps

# 如果未运行，启动数据库
docker compose up -d mysql redis
```

**原因 (Linux)**: 防火墙阻止连接或 MySQL 服务未启动。

**解决**:
```bash
# 检查 MySQL 状态
sudo systemctl status mysql

# 重启 MySQL
sudo systemctl restart mysql
```

---

### Q3: 端口 8000 无法访问

**原因 (Windows)**: 防火墙或杀毒软件阻止。

**解决**: 在 Windows Defender 防火墙中允许 Python 访问网络。

**原因 (Linux)**: 云服务器安全组未开放端口。

**解决**: 登录云服务商控制台，在安全组规则中添加入站规则：
- 协议: TCP
- 端口: 8000
- 源: 0.0.0.0/0

---

### Q4: Pillow 安装失败或图片处理报错

**原因**: 缺少图像处理库依赖。

**解决 (Windows)**: Pillow 通常自带二进制包，无需额外配置。

**解决 (Linux)**:
```bash
sudo apt install -y libjpeg-dev zlib1g-dev
pip install --force-reinstall Pillow
```

---

### Q5: `/assets` 目录权限问题

**现象**: 上传图片后无法访问静态资源。

**解决 (Linux)**:
```bash
# 创建 assets 目录并设置权限
mkdir -p /var/www/infinity-tag/assets
sudo chown -R www-data:www-data /var/www/infinity-tag/assets
sudo chmod -R 755 /var/www/infinity-tag/assets
```

---

### Q6: Docker Desktop 启动失败 (Windows)

**原因**: WSL2 未安装或版本过旧。

**解决**:
```powershell
# 以管理员身份运行 PowerShell
wsl --install
wsl --update

# 重启计算机后重新启动 Docker Desktop
```
