# 单片机 (ESP32) 端开发与部署指南

本指南将指导您如何在 ESP32 开发板上编写固件，使其能够连接 WiFi、请求后端生成的黄历位图，并驱动 2.13 寸墨水屏进行显示。

## 1. 硬件准备

*   **主控**: ESP32 开发板 (如 ESP32-S3, ESP32-C3 等)
*   **屏幕**: 2.13寸 电子墨水屏 (E-Ink Display)
    *   分辨率: 250x122 (必须匹配)
    *   常见驱动芯片: IL3897, SSD1680 (微雪/Waveshare 2.13 V4 等)
    *   接口: SPI
*   **连接线**: 杜邦线 (用于连接 SPI 接口)

### 接线示意 (以常见 ESP32 30Pin 开发板为例)

| 墨水屏引脚 | ESP32 引脚 (示例) | 描述 |
| :--- | :--- | :--- |
| VCC | 3.3V | 电源 (注意不要接 5V) |
| GND | GND | 地 |
| DIN | GPIO 23 (MOSI) | SPI 数据输入 |
| CLK | GPIO 18 (SCK) | SPI 时钟 |
| CS | GPIO 5 | 片选 |
| DC | GPIO 17 | 数据/命令控制 |
| RST | GPIO 16 | 复位 |
| BUSY | GPIO 4 | 忙状态检测 |

> **注意**: 具体引脚定义请根据您的开发板原理图修改代码中的定义。

## 2. 开发环境搭建

推荐使用 **Arduino IDE** 或 **PlatformIO (VS Code 插件)**。

### 依赖库安装

请在库管理器中搜索并安装以下库：

1.  **GxEPD2** (作者: Jean-Marc Zingg) - 强大的墨水屏驱动库，支持多种型号。
2.  **HTTPClient** (内置) - 用于发送 HTTP 请求。
3.  **WiFi** (内置) - 用于连接网络。

---

## 3. 核心逻辑说明

传统的墨水屏开发需要在单片机上进行复杂的绘图（画点、画线、写字），这需要消耗大量的 Flash 存储字库，且难以实现复杂的排版（如竖排、书法字体）。

**本项目采用“服务端渲染 (SSR)”方案：**

1.  **后端**: Python (`Pillow`) 生成 250x122 的图片 -> 转换为 1-bit 原始位图数据 (Binary) -> 通过 HTTP API 返回。
2.  **前端 (ESP32)**:
    *   连接 WiFi。
    *   访问 `/api/v1/renderer/bitmap`。
    *   下载二进制流。
    *   将数据流直接写入屏幕缓冲区。
    *   刷新屏幕。

这种方式使得 ESP32 固件极其简单、轻量，且 UI 修改无需重新烧录固件。

## 4. 示例代码 (Arduino Sketch)

将以下代码复制到您的 Arduino 项目中 (`main.cpp` 或 `.ino` 文件)。

```cpp
#include <WiFi.h>
#include <HTTPClient.h>

// 引入 GxEPD2 库
// 请根据您的屏幕型号选择对应的类，以下以微雪 2.13 V4 (SSD1680) 为例
#define ENABLE_GxEPD2_GFX 0
#include <GxEPD2_BW.h>

// --- 引脚定义 (请根据实际接线修改) ---
// ESP32 Standard SPI: SCK=18, MISO=19, MOSI=23
#define EPD_CS   5
#define EPD_DC   17
#define EPD_RST  16
#define EPD_BUSY 4

// 实例化屏幕驱动
// GxEPD2_213_B74 是微雪 2.13 V4 黑白屏 (250x122)
GxEPD2_BW<GxEPD2_213_B74, GxEPD2_213_B74::HEIGHT> display(GxEPD2_213_B74(EPD_CS, EPD_DC, EPD_RST, EPD_BUSY));

// --- WiFi 配置 ---
const char* ssid     = "YOUR_WIFI_SSID";
const char* password = "YOUR_WIFI_PASSWORD";

// --- 后端 API 配置 ---
// 注意: 如果在本地调试，请使用电脑的局域网 IP (如 192.168.1.x)，不要用 localhost
const char* apiUrl = "http://192.168.1.100:8000/api/v1/renderer/bitmap";
// const char* token  = "YOUR_AUTH_TOKEN"; // 如果 API 需要鉴权

// 缓冲区大小 (250 * 122 / 8 = 3812.5 bytes -> 约 4KB)
// 建议申请稍微大一点的 Buffer
#define IMG_BUF_SIZE 4000
uint8_t imageBuffer[IMG_BUF_SIZE];

void setup() {
  Serial.begin(115200);
  delay(1000);

  // 1. 初始化屏幕
  Serial.println("Initializing Display...");
  display.init(115200, true, 2, false); // 启用调试输出
  display.setRotation(1); // 0=竖屏, 1=横屏 (250x122)
  display.fillScreen(GxEPD_WHITE);
  display.display();

  // 2. 连接 WiFi
  Serial.print("Connecting to WiFi");
  WiFi.begin(ssid, password);
  while (WiFi.status() != WL_CONNECTED) {
    delay(500);
    Serial.print(".");
  }
  Serial.println("\nWiFi Connected!");
  Serial.print("IP Address: ");
  Serial.println(WiFi.localIP());

  // 3. 获取并显示黄历
  fetchAndDisplayAlmanac();

  // 4. 进入深度睡眠以省电 (可选)
  // Serial.println("Going to sleep...");
  // esp_deep_sleep_start();
}

void loop() {
  // 如果不使用深度睡眠，可以在这里定时刷新
  // delay(3600000); // 每小时刷新一次
}

// 核心函数: 下载并显示
void fetchAndDisplayAlmanac() {
  if (WiFi.status() != WL_CONNECTED) return;

  HTTPClient http;
  Serial.print("Fetching bitmap from: ");
  Serial.println(apiUrl);

  // 开始请求
  http.begin(apiUrl);
  // 如果需要鉴权:
  // http.addHeader("Authorization", "Bearer " + String(token));

  int httpCode = http.GET();

  if (httpCode == HTTP_CODE_OK) {
    // 获取内容长度
    int len = http.getSize();
    Serial.printf("Content-Size: %d bytes\n", len);

    if (len > IMG_BUF_SIZE) {
      Serial.println("Error: Image too large for buffer!");
      http.end();
      return;
    }

    // 读取数据流到缓冲区
    WiFiClient *stream = http.getStreamPtr();
    int bytesRead = 0;
    while (http.connected() && (len > 0 || len == -1)) {
      size_t size = stream->available();
      if (size) {
        int c = stream->readBytes(imageBuffer + bytesRead, size);
        bytesRead += c;
        if (len > 0) len -= c;
      }
      delay(1);
    }

    Serial.printf("Downloaded %d bytes.\n", bytesRead);

    // 绘制到屏幕
    // GxEPD2 的 drawImage 接收位图数据
    // 参数: bitmap, x, y, w, h, invert, mirror_y, pgm
    // 我们的后端生成的是 standard monochrome bitmap (MSB first, 1=White)
    // GxEPD2 默认通常是 0=Black, 1=White

    display.setFullWindow();
    display.firstPage();
    do {
      // 这里的 250, 122 必须与后端生成的尺寸一致
      // 注意：GxEPD2_BW 的 drawImage 可能需要适配数据格式
      // 如果显示花屏或反色，尝试调整 drawBitmap 的参数或后端 convert_to_epd_bitmap 的逻辑

      display.fillScreen(GxEPD_WHITE);
      // drawBitmap(x, y, data, w, h, color)
      // 注意: GxEPD2 继承自 Adafruit_GFX，drawBitmap 是绘制在该层上的
      // 我们直接绘制黑色的点

      display.drawBitmap(0, 0, imageBuffer, 250, 122, GxEPD_BLACK);

      // 如果发现颜色反了（背景黑，字白），将 GxEPD_BLACK 改为 GxEPD_WHITE
      // 或者在后端设置 invert=True

    } while (display.nextPage());

    Serial.println("Display Refreshed!");

  } else {
    Serial.printf("HTTP GET failed, error: %s\n", http.errorToString(httpCode).c_str());
  }

  http.end();
}
```

## 5. 常见问题排查 (Troubleshooting)

### Q1: 屏幕显示花屏或杂乱的噪点
*   **原因**: 位图数据的字节序 (MSB/LSB) 或 宽高设置不匹配。
*   **解决**:
    *   确保后端 `renderer_engine.py` 中的 `WIDTH=250`, `HEIGHT=122` 与屏幕完全一致。
    *   确保 `display.setRotation(1)` 设置正确（通常宽 > 高为横屏）。

### Q2: 屏幕全黑或全白，无图像
*   **原因**: 颜色定义反了。
*   **解决**: 尝试将代码中的 `display.drawBitmap(..., GxEPD_BLACK)` 改为 `GxEPD_WHITE`，或者在后端生成时反转颜色位。

### Q3: 无法连接后端 (HTTP Connect Failed)
*   **原因**: ESP32 无法访问 `localhost`。
*   **解决**: 确保后端运行在 `0.0.0.0` (如 `uvicorn app.main:app --host 0.0.0.0`)，并且 ESP32 代码中使用电脑的**局域网 IP** (如 `192.168.31.x`)，且两者连接同一个 WiFi。

### Q4: 字体显示为方块
*   **原因**: 服务器端缺少字体文件。
*   **解决**: 检查服务器日志，确保字体文件 `ChangBanDianSong-12.ttf` 存在于 `assets/fonts/` 目录下。
