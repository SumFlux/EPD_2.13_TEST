# 本地调试与测试指南

本文档旨在帮助开发者在本地环境中启动后端服务，并使用测试脚本验证 API 功能。

## 1. 启动后端服务

在运行测试之前，必须先启动后端服务。

### 方式一：直接运行 (推荐)

确保你已经安装了 Python 环境和依赖。

```bash
cd infinity-tag-backend

# 激活虚拟环境 (如果有)
# source venv/bin/activate  # Linux/Mac
# venv\Scripts\activate     # Windows

# 启动服务
uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
```

看到类似以下的输出即表示启动成功：
```
INFO:     Uvicorn running on http://0.0.0.0:8000 (Press CTRL+C to quit)
INFO:     Started reloader process [...] using StatReload
INFO:     Started server process [...]
INFO:     Waiting for application startup.
INFO:     Application startup complete.
```

### 方式二：Docker 启动

```bash
cd infinity-tag-backend
docker-compose up -d backend
```

## 2. 运行测试脚本

我们提供了一组 Python 脚本，用于按顺序验证核心业务流程。

### 准备工作

确保安装了测试脚本所需的依赖 (主要是 `httpx`)：

```bash
pip install httpx
```

### 步骤 1: 设备激活

此步骤模拟设备首次连接，获取 `access_token` 并保存到本地 (`.token` 文件)。

```bash
python scripts/test/01_activate.py
```

**成功输出示例：**
```

✅ 激活成功！
{
  "success": true,
  "data": {
    "access_token": "eyJhbGciOiJIUzI1NiIsInR...",
    "token_type": "bearer",
    "expires_in": 604800
  }
}
✅ Token 已保存至 scripts/test/.token
```

### 步骤 2: 设置档案

设置用户的生辰八字信息，这是生成个性化黄历的前提。

```bash
python scripts/test/02_set_profile.py
```

**成功输出示例：**
```

✅ 档案设置成功！
{
  "success": true,
  "data": {
    "nickname": "测试用户",
    "birth_year": 1990,
```

### 步骤 3: 生成黄历

请求生成今日黄历。此接口会调用 AI 服务，因此响应时间较长 (10-30秒)。


### 步骤 4: 清除缓存 (辅助工具)

如果需要强制重新生成黄历（忽略 Redis 缓存），可以使用此脚本清理指定日期的缓存。

```bash

python scripts/test/clean_cache.py

# 清除指定日期缓存
python scripts/test/clean_cache.py --date 2024-02-03
```

## 3. 常见问题排查 (Troubleshooting)

### Q1: Connection refused (连接被拒绝)
**现象**: `httpx.ConnectError: [Errno 111] Connection refused`
**原因**: 后端服务未启动或端口不正确。
**解决**: 检查 `uvicorn` 是否正在运行，且监听在 `8000` 端口。

### Q2: 401 Unauthorized
**现象**: `激活失败: 401` 或其他接口报 401。
**原因**: Token 过期或未正确传递。
**解决**: 重新运行 `python scripts/test/01_activate.py` 获取新 Token。

### Q3: 500 Internal Server Error (Database)
**现象**: 接口返回 500，日志显示数据库连接错误。
**原因**: 数据库未启动或配置错误。
**解决**:
1. 检查 MySQL 是否启动。
2. 检查 `.env` 文件中的 `MYSQL_PASSWORD` 是否正确。
3. 确保已运行 `python scripts/init_db.py` 初始化表结构。

### Q4: 500 Internal Server Error (AI Service)
**现象**: `generate_almanac` 返回 500 或超时。
**原因**: AI API Key 无效或余额不足，或网络不通，或超时时间设置过短。
**解决**:
1. 检查 `.env` 中的 `AI_API_KEY`。
2. 检查服务器是否能访问外网 (特别是 AI 服务商的 API 地址)。
3. 检查 `.env` 中的 `AI_TIMEOUT` 是否已设置为 60 或更高。
4. 查看后端日志获取详细错误信息。

### Q5: "档案未设置"
**现象**: 生成黄历时提示档案未设置。
**原因**: 跳过了步骤 2。
**解决**: 先运行 `python scripts/test/02_set_profile.py`。
