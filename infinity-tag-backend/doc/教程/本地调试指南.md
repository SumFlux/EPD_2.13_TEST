## 1. 环境准备

### 1.1 检查端口占用

在启动服务前，确保以下端口未被占用：

```bash
# Windows
netstat -ano | findstr ":8000 :3306 :6379"

# Linux/Mac
lsof -i :8000,3306,6379
```

如果有占用，请手动停止相关进程或修改配置文件中的端口。

### 1.2 环境变量配置

**首次运行**需要复制环境变量模板并修改配置：

```bash
cd infinity-tag-backend
cp .env.example .env
```

**关键配置项**（必须修改）：

| 变量 | 说明 | 示例值 |
|------|------|--------|
| `MYSQL_PASSWORD` | MySQL 数据库密码 | `infinitytag_password` |
| `JWT_SECRET_KEY` | JWT 签名密钥（生产环境务必替换） | 使用 `openssl rand -hex 32` 生成 |
| `AI_API_KEY` | AI 服务 API 密钥 | `sk-xxxxx` |

**开发环境建议配置**：
```env
DEBUG=True
ENVIRONMENT=development
FORCE_HTTPS=False
CORS_ORIGINS=["*"]
```

## 2. 启动后端服务

### 方式一：本地 Python 启动（推荐用于开发）

#### 步骤 1: 启动数据库 (Docker)

```bash
cd infinity-tag-backend

# 启动 MySQL 和 Redis
docker-compose up -d mysql redis

# 验证服务状态
docker-compose ps
```

**首次启动**还需要运行数据库迁移：

```bash
# 应用数据库 schema
alembic upgrade head
```

#### 步骤 2: 启动后端服务

```bash
# 激活虚拟环境 (Windows)
venv\Scripts\activate

# 启动 FastAPI 服务（开发模式，支持热重载）
uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
```

看到类似以下的输出即表示启动成功：

```
INFO:     Uvicorn running on http://0.0.0.0:8000 (Press CTRL+C to quit)
INFO:     Started reloader process [xxxxx] using WatchFiles
INFO:     Application startup complete.
[INFO] Infinity Tag Backend v1.0.0 启动成功！
[ENV] 环境: development
[DB]  数据库: localhost:3306/infinity_tag
```

#### 步骤 3: 验证服务

访问以下 URL 确认服务正常：

- **健康检查**: http://localhost:8000/health
- **API 文档**: http://localhost:8000/docs
- **静态资源**: http://localhost:8000/assets/

---

### 方式二：Docker 完整启动

适用于生产环境或快速验证：

```bash
cd infinity-tag-backend

# 启动所有服务 (包括 Nginx)
docker-compose up -d

# 查看日志
docker-compose logs -f backend
```

## 3. 运行测试脚本

我们提供了一组 Python 脚本，用于按顺序验证核心业务流程。

### 准备工作

确保安装了测试脚本所需的依赖：

```bash
pip install httpx requests pillow
```

### 步骤 1: 设备激活

此步骤模拟设备首次连接，获取 `access_token` 并保存到本地 (`.token` 文件)。

```bash
python scripts/test/01_activate.py
```

**成功输出示例：**
```
➤ 步骤 1: 设备激活 (POST /auth/activate)
✅ 激活成功！
{
  "access_token": "eyJhbGciOiJIUzI1NiIsInR...",
  "token_type": "bearer",
  "device_id": "ABC123"
}
✅ Token 已保存至 scripts/test/.token
```

### 步骤 2: 设置档案

设置用户的生辰八字信息，这是生成个性化黄历的前提。

```bash
python scripts/test/02_set_profile.py
```

### 步骤 3: 生成黄历

请求生成今日黄历。此接口会调用 AI 服务，因此响应时间较长 (10-30秒)。

```bash
python scripts/test/03_generate_almanac.py
```

## 4. 图片模块测试（新增）

从 v1.1 开始，后端新增了**自定义图片管理模块**，支持上传、裁剪、二值化处理等功能。

### 4.1 命令行测试脚本

**基础测试**（自动登录 → 上传 → 下载 Bitmap）：

```bash
python scripts/test_image_flow.py
```

**高级测试**（带参数的裁剪、旋转、阈值调节）：

```bash
python scripts/test_advanced_image_flow.py
```

输出示例：
```
[*] 连接后端: http://localhost:8000/api/v1
[+] 登录成功! Token: eyJhbGciOi...
[+] 预览成功! 耗时: 2075.99ms
    已保存预览结果到 'preview_result.png'
[+] 上传成功! ID: 3
[+] 最终图片 URL: /assets/custom_images/2/xxxx.png
```

### 4.2 GUI 测试工具（推荐）

我们提供了一个可视化的测试工具，完整模拟前端编辑器的交互流程：

```bash
python scripts/gui_test_client.py
```

**功能特性：**

1. **登录认证**：启动时弹出登录框（默认填入测试账号）
2. **图片选择**：点击按钮加载本地图片
3. **交互裁剪**：在原图上拖拽鼠标画出裁剪框（自动锁定 212:104 比例）
4. **参数调节**：
   - 旋转：0°/90°/180°/270°
   - 模式切换：抖动模式（照片）/ 阈值模式（文字）
   - 阈值滑块：0-255 可调（仅阈值模式）
   - 反色开关：黑白反转
5. **实时预览**：右侧显示墨水屏最终效果（212x104，已放大2倍）
6. **确认上传**：满意后点击按钮保存到服务器

**使用提示**：
- 拖拽裁剪框时会**自动保持 212:104 宽高比**（墨水屏实际分辨率）
- 预览图片即为 ESP32 设备最终显示的一模一样的效果
- 上传成功后会返回图片 ID 和访问 URL

## 5. 常见问题排查 (Troubleshooting)

### Q1: Connection refused (连接被拒绝)

**现象**: `httpx.ConnectError: [Errno 111] Connection refused`

**原因**: 后端服务未启动或端口不正确。

**解决**:
1. 检查 `uvicorn` 是否正在运行：`netstat -ano | findstr ":8000"`
2. 确认监听在 `0.0.0.0:8000`，而非 `127.0.0.1:8000`

---

### Q2: 401 Unauthorized

**现象**: `激活失败: 401` 或其他接口报 401。

**原因**: Token 过期或未正确传递。

**解决**: 重新运行 `python scripts/test/01_activate.py` 获取新 Token。

---

### Q3: 500 Internal Server Error (Database)

**现象**: 接口返回 500，日志显示 `Can't connect to MySQL server`。

**原因**: 数据库未启动或配置错误。

**解决**:
1. 检查 Docker 容器状态：`docker-compose ps`
2. 检查 `.env` 文件中的 `MYSQL_PASSWORD` 是否正确
3. 确保已运行数据库迁移：`alembic upgrade head`
4. 查看数据库日志：`docker-compose logs mysql`

---

### Q4: 500 Internal Server Error (AI Service)

**现象**: `generate_almanac` 返回 500 或超时。

**原因**: AI API Key 无效或余额不足，或网络不通。

**解决**:
1. 检查 `.env` 中的 `AI_API_KEY` 是否有效
2. 检查服务器是否能访问外网 (`curl https://www.dmxapi.cn`)
3. 增加超时时间：`.env` 中设置 `AI_TIMEOUT=60`
4. 查看后端日志获取详细错误信息

---

### Q5: "档案未设置"

**现象**: 生成黄历时提示档案未设置。

**原因**: 跳过了步骤 2。

**解决**: 先运行 `python scripts/test/02_set_profile.py`。

---

### Q6: GUI 测试工具报错 "Preview failed"

**现象**: GUI 中点击"刷新预览"后右侧显示错误信息。

**原因**:
1. 未登录或 Token 失效
2. 图片文件格式不支持
3. 后端服务未启动

**解决**:
1. 重新运行 GUI 工具并登录
2. 使用标准图片格式 (PNG/JPG/JPEG)
3. 检查后端服务状态和日志

---

### Q7: Docker 容器无法启动

**现象**: `docker-compose up -d` 报错或容器反复重启。

**原因**:
1. 端口冲突 (3306/6379 已被占用)
2. Docker 引擎未启动

**解决**:
1. 检查端口占用：`netstat -ano | findstr ":3306 :6379"`
2. 停止冲突服务或修改 `docker-compose.yml` 中的端口映射
3. 启动 Docker Desktop (Windows/Mac)

## 🛑 停止服务

### 停止 Python 后端

在运行 `uvicorn` 的终端按 `Ctrl+C`。

### 停止 Docker 服务

```bash
cd infinity-tag-backend

# 停止所有容器
docker-compose down

# 停止并删除数据卷（慎用！会清空数据库）
docker-compose down -v
```
