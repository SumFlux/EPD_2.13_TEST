## 环境准备

### 前端开发环境

```bash
# 进入前端目录
cd infinity-tag-frontend

# 安装依赖
npm install

# 启动开发服务器
npm run dev
```

访问地址：`http://localhost:5173`

### 后端服务

确保后端服务运行在 `http://localhost:8000`

```bash
# 进入后端目录
cd infinity-tag-backend

# 启动服务
python -m uvicorn app.main:app --reload --port 8000
```

### 环境变量配置

前端 `.env` 文件：
```env
VITE_API_BASE_URL=/api/v1
```

## 测试账号

### 方式一：使用已有测试账号

| 字段 | 值 |
|------|-----|
| 设备ID | `TEST-DEVICE-001` |
| 密码 | `test123456` |

### 方式二：激活新设备

1. 访问 `/setup` 页面
2. 选择「激活设备」标签
3. 设置密码（如：`mypassword123`）
4. 激活成功后记录返回的设备ID

### 方式三：通过 API 创建测试账号

```bash
# 激活新设备
curl -X POST http://localhost:8000/api/v1/auth/activate \
  -H "Content-Type: application/json" \
  -d '{"password": "test123456"}'

# 响应示例
{
  "access_token": "eyJ...",
  "token_type": "bearer",
  "device_secret": "abc123...",
  "user_id": 1,
  "device_id": "DEV-XXXXXXXX"
}
```

## 功能测试流程

### 1. 设备激活测试

#### 测试步骤
1. 访问 `http://localhost:5173/setup`
2. 确认页面显示「激活设备」和「登录」两个标签
3. 在「激活设备」标签下：
   - 输入密码：`testpass123`
   - 输入确认密码：`testpass123`
   - 点击「激活设备」
4. 验证跳转至 `/profile` 页面

#### 预期结果
- [x] 激活成功后跳转至档案页面
- [x] localStorage 中存储 `access_token`
- [x] localStorage 中存储 `device_id`

#### 异常测试
| 场景 | 操作 | 预期 |
|------|------|------|
| 密码过短 | 输入5位密码 | 提示「密码至少需要6位字符」 |
| 密码不匹配 | 两次密码不同 | 提示「两次输入的密码不一致」 |

### 2. 设备登录测试

#### 前置条件
- 已有激活的设备账号

#### 测试步骤
1. 访问 `http://localhost:5173/setup`
2. 切换到「登录」标签
3. 输入设备ID和密码
4. 点击「登录」

#### 当前已知问题
> ⚠️ **Bug**: 登录页面的设备ID输入框为只读状态，无法手动输入

**临时解决方案**：
- 使用浏览器开发者工具修改 localStorage：
```javascript
localStorage.setItem('device_id', 'YOUR-DEVICE-ID')
```
- 或直接修改代码允许输入

### 5. 图片管理测试

#### 测试步骤
1. 访问 `/images`
2. 点击「选择图片」上传一张测试图片
3. 调整处理选项：

5. 点击「上传图片」
6. 验证图片列表更新
7. 点击「删除」测试删除功能

#### 预期结果
- [x] 预览实时更新
- [x] 上传成功后列表显示新图片
- [x] 删除后列表移除图片
- [x] 图片数量限制为5张

#### 验证 API
```bash

curl -X POST http://localhost:8000/api/v1/images/ \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -F "image=@test.jpg" \
  -F "rotate=0" \
  -F "dither=true"

  -H "Authorization: Bearer YOUR_TOKEN"

# 删除图片
```

## 常见问题排查

### 1. 页面空白

**可能原因**：
- TypeScript 编译错误
- 模块导入错误

**排查步骤**：
```bash
# 检查 TypeScript 编译
npx tsc --noEmit

# 查看浏览器控制台错误
F12 -> Console
```

### 2. API 请求 401

**可能原因**：
- Token 过期或无效
- 未携带 Authorization 头

**排查步骤**：
```javascript
// 检查 localStorage
console.log(localStorage.getItem('access_token'))

// 检查请求头
// Network -> 请求 -> Headers
```

### 3. 跨域错误 (CORS)

**可能原因**：
- 后端未配置 CORS
- Vite 代理未生效

**解决方案**：
确认 `vite.config.ts` 代理配置：
```typescript
server: {
  proxy: {
    '/api': {
      target: 'http://localhost:8000',
      changeOrigin: true,
    },
  },
}
```

### 4. 图片预览失败

**可能原因**：
- 后端图片处理服务未启动
- 图片格式不支持

**排查步骤**：
```bash
# 直接测试后端预览接口
curl -X POST http://localhost:8000/api/v1/images/preview \
  -F "image=@test.jpg" \
  --output preview.png
```
