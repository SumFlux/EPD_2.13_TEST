## 产品简介

**无止便签** 是一款结合传统玄学与现代科技的电子挂件。通过 Web 端配置您的个人档案，设备将为您提供个性化的每日运势指引。

### 核心功能

| 功能 | 说明 |
|------|------|
| 设备激活 | 首次使用时绑定设备并设置密码 |
| 用户档案 | 配置八字、职业、关注点等信息 |
| 智能黄历 | 查看每日运势、宜忌、吉方吉物 |
| 图片管理 | 上传自定义图片到设备显示 |

## 快速开始

### 第一步：激活设备

1. 扫描设备上的二维码，进入 Web 配置页面
2. 在「激活设备」页面设置密码（至少6位）
3. 确认密码后点击「激活设备」
4. **重要**：激活成功后会显示「设备密钥」，请妥善保管用于设备恢复

### 第二步：配置档案

激活成功后自动跳转至档案页面：

1. **昵称**：输入您的称呼
2. **性别**：选择男/女
3. **出生日期**：选择年、月、日
   - 勾选「农历」如果您的生日是农历
4. **出生时辰**：选择时辰（可选「未知」）
5. **职业**：选择您的职业类别
6. **关注点**：填写近期关注的事项（如：事业发展、感情问题）
7. 点击「保存档案」

### 第三步：查看运势

保存档案后自动跳转至运势页面：

- **今日运势**：显示当日详细运势信息
- **历史回顾**：查看过去30天的运势记录

## 功能详解

### 1. 设备激活与登录

#### 激活新设备
- 扫码后选择「激活设备」标签
- 设置并确认密码
- 激活成功后保存设备密钥

#### 已激活设备登录
- 选择「登录」标签
- 输入设备ID和密码
- 点击「登录」

### 2. 用户档案

档案信息用于生成个性化运势，信息越完整，运势越精准。

| 字段 | 说明 | 必填 |
|------|------|------|
| 昵称 | 您的称呼 | 是 |
| 性别 | 男/女 | 是 |
| 出生日期 | 公历或农历生日 | 是 |
| 出生时辰 | 十二时辰 | 否 |
| 职业 | 职业类别 | 否 |
| 关注点 | 近期关注事项 | 否 |

#### 时辰对照表

| 时辰 | 时间范围 |
|------|----------|
| 子时 | 23:00-01:00 |
| 丑时 | 01:00-03:00 |
| 寅时 | 03:00-05:00 |
| 卯时 | 05:00-07:00 |
| 辰时 | 07:00-09:00 |
| 巳时 | 09:00-11:00 |
| 午时 | 11:00-13:00 |
| 未时 | 13:00-15:00 |
| 申时 | 15:00-17:00 |
| 酉时 | 17:00-19:00 |
| 戌时 | 19:00-21:00 |
| 亥时 | 21:00-23:00 |

### 3. 智能黄历

#### 今日运势
- **农历日期**：当日农历
- **干支纪年**：年、月、日的天干地支
- **能量等级**：0-100 的运势评分
- **宜**：今日适宜之事
- **忌**：今日不宜之事
- **吉方**：今日吉利方位
- **吉物**：今日开运物品
- **运势解读**：AI 生成的个性化运势分析

#### 历史回顾
- 日历视图显示最近30天
- 彩色圆点表示当日能量等级
  - 🟢 绿色：高能量（70+）
  - 🟡 黄色：中能量（40-69）
  - 🔴 红色：低能量（0-39）
- 点击日期查看详细运势

### 4. 图片管理

上传自定义图片到设备显示（最多5张）。

#### 上传流程
1. 点击「选择图片」选择本地图片
2. 调整图片处理选项：
   - **旋转**：0°/90°/180°/270°
   - **反色**：适合浅色背景图片
   - **抖动算法**：推荐开启，显示效果更细腻
   - **阈值**：关闭抖动时可调节黑白阈值
3. 实时预览处理效果
4. 点击「上传图片」

#### 管理图片
- 查看已上传图片列表
- 删除不需要的图片
- 图片显示查看次数统计

## 常见问题

### Q: 忘记密码怎么办？
A: 使用激活时保存的「设备密钥」可以恢复设备。如密钥也丢失，请联系客服。

### Q: 运势多久更新一次？
A: 每日凌晨自动更新。也可手动刷新获取最新运势。

### Q: 图片上传失败？
A: 请检查：
- 图片格式是否为 JPG/PNG
- 图片大小是否超过 5MB
- 已上传图片是否达到5张上限

### Q: 设备显示与预览不一致？
A: 设备使用电子墨水屏，仅支持黑白显示。建议：
- 使用高对比度图片
- 开启「抖动算法」获得更好的灰度效果
- 调整「阈值」优化显示效果
