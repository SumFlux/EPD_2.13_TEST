## 🔄 步骤一：切换到新主程序

当前项目同时存在 `main.cpp` (旧版) 和 `main_new.cpp` (新框架)。需要**临时切换**到新版本进行测试。

### 方法 A：重命名文件（推荐）

```powershell
cd f:\Documents\SumProject\5.1_EPD_TEST\infinity-tag-esp32\src

# 备份旧的 main.cpp
ren main.cpp main_old.cpp.bak

# 启用新的 main_new.cpp
ren main_new.cpp main.cpp
```

### 方法 B：使用 PlatformIO 的 build_flags（高级）

在 `platformio.ini` 中添加：

```ini
src_filter = +<*> -<main_old.cpp>
```

## 🔨 步骤二：编译固件

```powershell
cd f:\Documents\SumProject\5.1_EPD_TEST\infinity-tag-esp32

# 编译
pio run
```

### 常见编译问题及解决方案

#### 问题 1：找不到 `LittleFS.h`

**解决**：确保 `platformio.ini` 包含：

```ini
board_build.filesystem = littlefs
```

#### 问题 2：找不到 `WebServer.h`

**解决**：ESP32 Arduino Core 自带，无需额外依赖。如果仍然报错，检查 platform 版本：

```ini
platform = espressif32@^6.0.0
```

#### 问题 3：`qrcode.h` 找不到

**解决**：确保 `lib_deps` 包含：

```ini
lib_deps =
    ...
    ricmoo/QRCode@^0.0.1
```

## 🧪 步骤四：测试功能

### 测试 1：启动流程

**预期行为**：

1. 屏幕显示进度条 "Starting..." (Step 1/6 ~ 6/6)
2. 串口输出：
   ```
   ========================================
     INFINITY TAG V2 - Lua Card Engine
   ========================================
   [CRITICAL] PWR_IO set to HIGH - Power hold enabled
   Firmware: v1.0.0.x
   [OK] Hardware initialized
   [LittleFS] Mounted successfully
   [OK] Config loaded
   [OK] Core initialized
   [Cards] Registered 1 cards
   ```

**验证点**：
- [ ] 进度条正常显示
- [ ] 串口无错误信息
- [ ] LittleFS 初始化成功

---

### 测试 2：设置卡片 (SettingsCard) & WiFi 配网

**触发条件**：
- 首次启动：自动进入 SettingsCard 的 WiFi 配网模式
- 正常启动：通过左右切换进入 SettingsCard

**测试步骤 A：WiFi 配网**
1. 设备显示 "WiFi Setup" 和二维码
2. 手机扫描二维码或连接热点 `InfinityTag-XXXX`
3. 手机弹出配网页面，输入 WiFi 信息并保存
4. **预期**：设备自动重启并连接 WiFi

**测试步骤 B：功能菜单**
1. 进入 SettingsCard（显示 "Settings" 标题）
2. **单击**：切换菜单项
   - WiFi Info
   - Check Update
   - System Info
   - Reboot
3. **长按**：执行当前选中的菜单项

**验证点**：
- [ ] 能正常显示 WiFi IP 和信号强度
- [ ] 能显示 System Info (版本号、运行时间、内存)
- [ ] 长按 Reboot 能重启设备

---

### 测试 3：OTA 固件更新

**前提**：
- 设备已连接 WiFi
- 后端服务已启动 (如果不具备真实后端，OTAManager 会模拟检测失败或无更新)

**测试步骤**：
1. 在 SettingsCard 中选择 "Check Update"
2. **长按** 确认
3. **预期**：
   - 屏幕显示 "Checking..."
   - 如果有更新：显示新版本信息 -> 长按 "Install" -> 显示进度条 -> 自动重启
   - 如果无更新：显示 "No Update" -> 3秒后返回
   - 如果失败：显示 "Check Failed" -> 3秒后返回

---

### 测试 4：事件系统（InputManager）

**测试步骤**：

1. **单击按钮**：
   - 在 SettingsCard 中切换菜单项
   - 串口输出：`[InputManager] Button press`

2. **长按按钮 (1秒以上)**：
   - 进入卡片切换模式（如果不在设置菜单中）
   - 在设置菜单中执行选中的功能
   - 串口输出：`[InputManager] Long press detected`

3. **三击按钮**：
   - 预期产生事件：`EVENT_BUTTON_TRIPLE_CLICK`

4. **旋转编码器**：
   - 在卡片切换模式下切换卡片
   - 串口输出：`EVENT_ENCODER_ROTATE`

5. **摇晃设备**：
   - 预期产生事件：`EVENT_VIBRATION`

---

### 测试 4：配置管理器（NVS 持久化）

**测试步骤**：

1. 配置 WiFi 后重启设备
2. 检查是否自动连接到之前配置的 WiFi

**验证点**：
- [ ] WiFi SSID 和密码正确持久化到 NVS
- [ ] 重启后自动读取并连接

## ⚠️ 注意事项

1. **测试完成后**，如需恢复旧固件：
   ```powershell
   ren main.cpp main_new.cpp
   ren main_old.cpp.bak main.cpp
   ```

2. **二维码大小**：当前使用 QR Code Version 3，80x80 像素，在 2.13 寸屏幕上略小。如果扫描困难，可以修改 `_renderQRCode()` 中的 scale 参数。

3. **Captive Portal 兼容性**：部分 Android 手机可能不会自动弹出配网页面，需要手动打开浏览器访问 `http://192.168.4.1`。
