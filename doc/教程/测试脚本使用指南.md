## 固件上传脚本 (upload_firmware.py)

用于通过 API 将固件文件上传到服务器，便于测试 OTA 功能。

### 前置条件
- Python 3.x
- 安装 `requests` 库 (`pip install requests`)
- 后端服务已启动
- **关键**: 确保后端根目录下配置了正确的 `.env` 文件 (需包含 `JWT_SECRET_KEY` 和 `ADMIN_USERNAME`)

### 用法

```bash
python scripts/upload_firmware.py <固件文件路径> <版本号> [选项]
```

### 参数说明

| 参数 | 必选 | 说明 | 默认值 |
|------|------|------|--------|
| `file` | 是 | 固件文件路径 (.bin) | - |
| `version` | 是 | 版本号 (格式: A.B.C.D) | - |
| `--desc` | 否 | 固件描述 | None |
| `--url` | 否 | 后端 API 地址 | http://localhost:8000 |

### 示例

**基本用法 (自动读取 .env 配置):**
```bash
python scripts/upload_firmware.py firmware.bin 1.0.0.1 --desc "Initial release"
```

**指定远程服务器 (Token 仍由本地 .env 生成):**
```bash
python scripts/upload_firmware.py firmware.bin 1.0.0.2 \
  --url http://192.168.1.100:8000 \
  --desc "Fix bug"
```
