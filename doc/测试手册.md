# 无止便签 (Infinity Tag) 完整测试手册

本手册覆盖前端 UI 交互测试与后端 API 功能测试，按业务流程组织，建议按顺序执行。

---

## 测试环境准备

### 1. 启动后端服务

```bash
cd infinity-tag-backend
source venv/bin/activate  # Windows: venv\Scripts\activate
uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
```

验证：访问 http://localhost:8000/docs 应显示 Swagger 文档

### 2. 启动前端服务

```bash
cd infinity-tag-frontend
pnpm dev
```

验证：访问 http://localhost:5173 应显示页面

### 3. 数据库准备

确保 MySQL 和 Redis 服务已启动，数据库已迁移：

```bash
cd infinity-tag-backend
alembic upgrade head
```

### 4. 必填环境变量

确保 `.env` 文件包含以下必填项：

| 变量名 | 说明 | 示例 |
|--------|------|------|
| `JWT_SECRET_KEY` | JWT 签名密钥 | 随机字符串 |
| `DEVICE_CODE_SALT` | 设备码生成盐值 | 随机字符串 |
| `INIT_PWD_SALT` | 初始密码生成盐值 | 随机字符串 |
| `ADMIN_PASSWORD_HASH` | 管理员密码哈希 | bcrypt 格式 |

生成管理员密码哈希：
```bash
python -c "from passlib.context import CryptContext; print(CryptContext(schemes=['bcrypt']).hash('your-password'))"
```
