# Lua 脚本卡片引擎技术方案

> **版本**: 1.0  
> **日期**: 2026-02-07  
> **状态**: 待评估

---

## 1. 背景与目标

### 1.1 需求背景

Infinity Tag 墨水屏胸牌需要支持多种功能卡片（图片展示、黄历、木鱼、摇签等）。用户希望能够通过 Web 端灵活选择和安装卡片，并实现**秒级安装、无需重启设备**的极致体验。

### 1.2 技术目标

- **热加载**：新卡片下载后立即运行，无需重启设备
- **安全沙箱**：卡片代码 Bug 不会导致设备崩溃
- **轻量高效**：脚本文件仅 KB 级，下载秒级完成
- **开发友好**：Lua 语法简单，降低卡片开发门槛

## 2. 技术架构

### 2.1 分层架构

```
┌─────────────────────────────────────────────────┐
│                  Lua 卡片层                      │
│  (pomodoro.lua, calendar.lua, muyu.lua ...)    │
├─────────────────────────────────────────────────┤
│               Lua API 绑定层                     │
│  (C++ 封装的 eink.*, wifi.*, nvs.* 等接口)      │
├─────────────────────────────────────────────────┤
│               Lua 虚拟机 (Lua 5.4)               │
├─────────────────────────────────────────────────┤
│                C++ 核心固件层                    │
│  (EPD驱动, WiFi, HTTP, NVS, 电源管理, OTA)      │
├─────────────────────────────────────────────────┤
│                   ESP32-S3 硬件                  │
│  (8MB PSRAM, 16MB Flash, E-Paper 212x104)       │
└─────────────────────────────────────────────────┘
```

### 2.2 核心组件

| 组件 | 职责 | 技术选型 |
|------|------|----------|
| **Lua 虚拟机** | 解释执行 Lua 脚本 | Lua 5.4 (标准实现) |
| **API 绑定层** | 将 C++ 硬件接口暴露给 Lua | lua_register() 原生绑定 |
| **卡片管理器** | 管理卡片生命周期、切换、事件分发 | C++ CardManager 类 |
| **文件系统** | 存储卡片脚本文件 | LittleFS (SPIFFS 升级版) |

## 3. 卡片下载与运行流程

### 3.1 流程图

```
用户 (Web)          后端服务器              ESP32 设备
    │                    │                       │
    │  1. 选择安装卡片    │                       │
    │ ─────────────────► │                       │
    │                    │                       │
    │                    │  2. 记录设备-卡片绑定  │
    │                    │ ──────────────────────►│ (Webhook/轮询)
    │                    │                       │
    │                    │  3. 返回卡片下载地址   │
    │                    │ ◄──────────────────── │
    │                    │                       │
    │                    │  4. 下载 .lua 脚本    │
    │                    │ ◄──────────────────── │
    │                    │ ─────────────────────►│
    │                    │                       │
    │                    │                       │ 5. 保存到 /cards/
    │                    │                       │
    │                    │                       │ 6. 热加载脚本
    │                    │                       │    luaL_dofile()
    │                    │                       │
    │                    │                       │ 7. 屏幕刷新
    │                    │                       │    显示新卡片
```

### 3.2 关键步骤说明

1. **下载**：ESP32 发起 HTTP GET 请求，下载 `.lua` 文本文件（通常 1-10 KB）
2. **存储**：保存到 LittleFS 文件系统 `/cards/card_name.lua`
3. **热加载**：调用 `luaL_dofile()` 立即执行脚本
4. **生效**：无需重启，屏幕立即显示新卡片界面

## 4. Lua API 设计

### 4.1 暴露给 Lua 的 C++ 接口

#### 4.1.1 墨水屏绘图 (eink.*)

```lua
eink.clear()                          -- 清屏
eink.drawPixel(x, y, color)           -- 画点
eink.drawLine(x1, y1, x2, y2)         -- 画线
eink.drawRect(x, y, w, h)             -- 画矩形
eink.fillRect(x, y, w, h)             -- 填充矩形
eink.drawStr(x, y, "文本")            -- 绘制文本
eink.setFont("u8g2_font_ncenB14")     -- 设置字体
eink.refresh()                        -- 全刷
eink.refreshPartial()                 -- 局刷
```

#### 4.1.2 永久存储 (nvs.*)

```lua
nvs.set("key", "value")               -- 存储键值对
local val = nvs.get("key")            -- 读取数据
nvs.remove("key")                     -- 删除数据
```

#### 4.1.3 网络请求 (http.*)

```lua
local resp = http.get("https://api.example.com/data")
local json = http.post(url, body, headers)
```

#### 4.1.4 硬件控制 (hw.*)

```lua
hw.vibrate(100)                       -- 震动 100ms
hw.beep(440, 200)                     -- 蜂鸣器 440Hz 响 200ms
hw.sleep()                            -- 进入深度睡眠
```

#### 4.1.5 事件回调 (由系统调用)

```lua
function onInit()      end            -- 卡片初始化
function onLoop()      end            -- 主循环 (每帧调用)
function onBtnPress()  end            -- 按键按下
function onBtnLong()   end            -- 按键长按
function onEncoderCW() end            -- 编码器顺时针
function onEncoderCCW() end           -- 编码器逆时针
function onShake()     end            -- 设备被摇晃
```

### 4.2 示例卡片：番茄钟

```lua
-- pomodoro.lua
local remaining = 25 * 60  -- 25分钟
local running = false

function onInit()
    eink.clear()
    drawTimer()
end

function onBtnPress()
    running = not running
    hw.vibrate(50)
end

function onLoop()
    if running and remaining > 0 then
        remaining = remaining - 1
        drawTimer()
        eink.refreshPartial()
    end
end

function drawTimer()
    local min = math.floor(remaining / 60)
    local sec = remaining % 60
    eink.clear()
    eink.setFont("u8g2_font_ncenB24")
    eink.drawStr(50, 60, string.format("%02d:%02d", min, sec))
end
```

## 5. 资源评估

### 5.1 内存占用

| 组件 | RAM 占用 | Flash 占用 |
|------|----------|------------|
| Lua 虚拟机 | ~60 KB | ~100 KB |
| API 绑定层 | ~10 KB | ~50 KB |
| 卡片管理器 | ~5 KB | ~20 KB |
| **总计** | **~75 KB** | **~170 KB** |

> ESP32-S3 拥有 8MB PSRAM 和 16MB Flash，资源充裕。

### 5.2 性能评估

| 场景 | C++ 原生 | Lua 脚本 | 差异 |
|------|----------|----------|------|
| 绘制 100 个像素 | 0.1 ms | 0.5 ms | 5x (可忽略) |
| HTTP 请求 | 100 ms | 101 ms | 1% (网络延迟主导) |
| 墨水屏刷新 | 300 ms | 300 ms | 0% (硬件决定) |

> 结论：对于墨水屏应用（刷新率 1-2 FPS），Lua 性能完全足够。

## 8. 风险与应对

| 风险 | 影响 | 应对措施 |
|------|------|----------|
| Lua 脚本执行过慢 | 界面卡顿 | 对 onLoop() 执行时间设限，超时降级 |
| 脚本语法错误 | 黑屏 | 错误时显示"脚本错误"提示，而非黑屏 |
| 恶意脚本 (死循环) | 设备卡死 | 为脚本执行设置超时看门狗 |
| 脚本访问敏感 API | 安全风险 | 限制 http.* 只能访问白名单域名 |

---

## 9. 结论与建议

**推荐采用 Lua 脚本引擎方案**，理由如下：

1. **用户体验最佳**：秒级安装、无需重启、热加载
2. **开发成本可控**：约 7 天可完成基础框架
3. **稳定性有保障**：沙箱隔离，脚本错误不影响系统
4. **扩展性极强**：未来可开放用户自制卡片

如需进一步讨论技术细节，欢迎联系开发团队。
