## 1. 硬件概述

### 1.1 屏幕参数

| 参数 | 规格 |
|------|------|
| 屏幕尺寸 | 2.13 英寸 |
| 分辨率 | 212 × 104 像素 |
| 驱动 IC | IL3897 (GxEPD2 中标识为 B72) |
| 显示颜色 | 黑/白双色 |
| 刷新类型 | 全刷 + 局部刷新 |
| 接口 | SPI |
| 工作电压 | 3.3V |

### 1.2 引脚连接 (ESP32-S3)

```
┌─────────────┬──────────┐
│   墨水屏     │  ESP32   │
├─────────────┼──────────┤
│   MOSI      │  GPIO5   │
│   SCLK      │  GPIO6   │
│   CS        │  GPIO7   │
│   DC        │  GPIO17  │
│   RES       │  GPIO18  │
│   BUSY      │  GPIO8   │
│   VCC       │  3.3V    │
│   GND       │  GND     │
└─────────────┴──────────┘
```

### 1.3 引脚功能说明

| 引脚 | 功能 | 说明 |
|------|------|------|
| **MOSI** | 主出从入 | SPI 数据输出，向屏幕发送像素数据 |
| **SCLK** | 时钟线 | SPI 时钟信号 |
| **CS** | 片选 | 低电平有效，选中屏幕芯片 |
| **DC** | 数据/命令 | 高=数据，低=命令 |
| **RES** | 复位 | 低电平复位屏幕 |
| **BUSY** | 忙状态 | 高电平=忙碌（正在刷新），低电平=空闲 |

## 3. 基础初始化

### 3.1 显示对象声明

```cpp
// IL3897 驱动，2.13寸屏幕
GxEPD2_BW<GxEPD2_213_B72, GxEPD2_213_B72::HEIGHT> display(
    GxEPD2_213_B72(PIN_CS, PIN_DC, PIN_RST, PIN_BUSY)
);
```

### 3.2 初始化流程

```cpp
void setup() {
    // 1. 电源使能（如果硬件有该引脚）
    pinMode(PIN_POWER_EN, OUTPUT);
    digitalWrite(PIN_POWER_EN, HIGH);
    delay(100);  // 等待电源稳定

    // 2. 串口初始化（调试用）
    Serial.begin(115200);

    // 3. SPI 初始化（必须先 end 再 begin）
    SPI.end();
    SPI.begin(PIN_SCK, -1, PIN_MOSI, PIN_CS);
    //        时钟     MISO(不用)  MOSI    CS

    // 4. 墨水屏初始化
    display.init(115200, true, 2, false);
    // 参数说明：
    // - 115200: 串口调试波特率
    // - true:   初始刷新使能
    // - 2:      复位脉冲时间(ms)
    // - false:  是否拉高CS保持

    // 5. 设置屏幕方向
    display.setRotation(1);  // 0-3 可选，1=横屏
}
```

> [!IMPORTANT]
> **SPI.begin() 参数顺序**：在 ESP32 上是 `SPI.begin(SCK, MISO, MOSI, SS)`，与传统 Arduino 不同！

## 4. 全刷模式

### 4.1 什么是全刷？

全刷（Full Refresh）是墨水屏的标准刷新模式：
- **刷新整个屏幕**的所有像素
- 会有**明显的黑白闪烁**（2-3 次）
- 刷新时间约 **2-3 秒**
- 画质最好，**无残影**

### 4.2 全刷实现

```cpp
void fullRefreshDemo() {
    // 1. 设置全屏窗口
    display.setFullWindow();
    
    // 2. 使用分页模式绘制（节省内存）
    display.firstPage();
    do {
        // 清屏为白色
        display.fillScreen(GxEPD_WHITE);
        
        // 绘制内容
        display.setTextColor(GxEPD_BLACK);
        display.setTextSize(2);
        display.setCursor(10, 50);
        display.print("Hello World!");
        
    } while (display.nextPage());
}
```

### 4.3 全刷使用场景

- ✅ 程序启动时的**首次清屏**
- ✅ 显示内容**大幅变化**时
- ✅ 长时间运行后**消除残影**
- ✅ 对**画质要求高**的静态展示

## 5. 局部刷新（快刷）

### 5.1 什么是局部刷新？

局部刷新（Partial Refresh）是墨水屏的快速刷新模式：
- 只刷新**指定区域**的像素
- **无闪烁**或闪烁极少
- 刷新时间约 **0.3-0.5 秒**
- 可能有**轻微残影**累积

### 5.2 局部刷新实现

```cpp
void partialRefreshDemo() {
    // 1. 定义刷新区域
    int x = 80;   // 起始X坐标
    int y = 40;   // 起始Y坐标
    int w = 60;   // 宽度
    int h = 50;   // 高度
    
    // 2. 设置局部窗口
    display.setPartialWindow(x, y, w, h);
    
    // 3. 绘制内容
    display.firstPage();
    do {
        display.fillScreen(GxEPD_WHITE);  // 先清除区域
        display.setCursor(x + 15, y + 10);
        display.setTextColor(GxEPD_BLACK);
        display.setTextSize(4);
        display.print("8");
    } while (display.nextPage());
}
```

### 5.3 ⚡ 极速局刷优化（Turbo Mode）

这是本项目验证的**核心优化技术**，可实现高速连续刷新：

```cpp
void turboPartialRefresh() {
    display.setTextSize(4);
    
    int x = 80, y = 40, w = 60, h = 50;
    display.setPartialWindow(x, y, w, h);

    for(int i = 0; i < 50; i++) {
        
        // ━━━ 阶段 A: 橡皮擦 (闪白) ━━━
        display.firstPage();
        do {
            display.fillScreen(GxEPD_WHITE); 
        } while (display.nextPage());
        
        // 【关键优化 1】
        // nextPage() 返回意味着 BUSY 刚刚释放
        // 只需 20ms 缓冲让电压稳定
        delay(20); 
        
        // ━━━ 阶段 B: 写入 (显黑) ━━━
        display.firstPage();
        do {
            display.fillScreen(GxEPD_WHITE);
            display.drawRect(x, y, w, h, GxEPD_BLACK);
            display.setCursor(x + 15, y + 10);
            display.setTextColor(GxEPD_BLACK);
            display.print(i % 10); 
        } while (display.nextPage());
        
        // 【关键优化 2】
        // 再次给 20ms 缓冲，准备下一次循环
        delay(20); 
    }
}
```

### 5.4 双重刷新机制解析

```
┌─────────────────────────────────────────────────────────┐
│                    双重刷新流程                          │
├─────────────────────────────────────────────────────────┤
│                                                         │
│  ┌─────────────┐         ┌─────────────┐               │
│  │  阶段 A     │  20ms   │  阶段 B     │               │
│  │  闪白清除   │ ──────► │  写入内容   │               │
│  │  (橡皮擦)   │  缓冲   │  (显示数字) │               │
│  └─────────────┘         └─────────────┘               │
│        │                       │                        │
│        ▼                       ▼                        │
│   清除墨水粒子             重新排列粒子                  │
│   防止残影累积             显示新内容                    │
│                                                         │
└─────────────────────────────────────────────────────────┘
```

**为什么需要双重刷新？**

1. **墨水屏原理**：通过电场控制黑白墨水粒子上下移动
2. **残影问题**：直接覆盖写入会导致旧内容"影子"残留
3. **解决方案**：先用白色"擦除"旧内容，再写入新内容

### 5.5 局刷注意事项

> [!WARNING]
> **关键限制**

| 注意事项 | 说明 |
|----------|------|
| **区域对齐** | 某些驱动要求 x 坐标和宽度为 8 的倍数 |
| **残影累积** | 连续局刷 100+ 次后建议执行一次全刷 |
| **刷新间隔** | 每次刷新后至少等待 BUSY 释放 + 20ms |
| **温度影响** | 低温环境下刷新速度明显变慢 |

## 6. 对比度恢复策略

连续局刷会导致墨水粒子“疲劳”，造成对比度下降。需要定期执行对比度恢复。

### 6.1 轻度恢复（闪白）

每几次局刷后执行一次闪白，保持对比度：

```cpp
void lightRecovery(int x, int y, int w, int h) {
  display.setPartialWindow(x, y, w, h);
  display.firstPage();
  do {
    display.fillScreen(GxEPD_WHITE);
  } while (display.nextPage());
  waitBusyWithMargin();
}
```

### 6.2 深度恢复（黑白交替）

每 20-30 次局刷后执行一次全屏黑白刷新：

```cpp
void contrastRecovery() {
  // 使用全屏 partial window 而非 setFullWindow
  // 避免触发库的多次闪烁 LUT
  display.setPartialWindow(0, 0, SCREEN_WIDTH, SCREEN_HEIGHT);
  
  display.firstPage();
  do {
    display.fillScreen(GxEPD_BLACK);
  } while (display.nextPage());
  waitBusyWithMargin();
  
  display.firstPage();
  do {
    display.fillScreen(GxEPD_WHITE);
  } while (display.nextPage());
  waitBusyWithMargin();
}
```

### 6.3 推荐策略

```cpp
#define FLASH_WHITE_N 3         // 每3次轻度恢复
#define CONTRAST_RECOVERY_N 20  // 每20次深度恢复

static uint16_t g_partialCount = 0;

void checkRecovery() {
  g_partialCount++;

  if (g_partialCount >= CONTRAST_RECOVERY_N) {
    contrastRecovery();
    g_partialCount = 0;
    return;
  }

  if ((g_partialCount % FLASH_WHITE_N) == 0) {
    lightRecovery(x, y, w, h);
  }
}
```

## 7. 性能优化技巧

### 7.1 延时优化

```cpp
// ❌ 传统做法（慢）
delay(200);  // 固定等待 200ms

// ✅ 优化做法（快）
// GxEPD2 的 nextPage() 内部已经等待 BUSY 释放
// 我们只需额外给 20ms 让电压稳定
delay(20);
```

**速度提升**：从每次刷新 400ms+ 降低到约 100ms

### 7.2 内存优化

GxEPD2 使用**分页模式**，大幅减少内存占用：

```cpp
// 分页模式：只需 (宽度/8) × 页高度 的缓冲区
display.firstPage();
do {
    // 绘制操作
} while (display.nextPage());  // 自动分页传输
```

**内存对比**：
- 全缓冲：212 × 104 / 8 ≈ **2.7 KB**
- 分页（页高=16）：212 × 16 / 8 ≈ **0.4 KB**

### 7.3 BUSY 检测

```cpp
// 库函数已自动处理 BUSY 等待
// 如需手动检测：
while (digitalRead(PIN_BUSY) == HIGH) {
    delay(1);  // 等待屏幕空闲
}
```

### 7.4 休眠模式

```cpp
// 刷新完成后进入深度休眠，大幅降低功耗
display.hibernate();

// 功耗对比：
// - 正常待机：~1mA
// - 休眠模式：~0.01mA
```

## 8. 常见问题与解决方案

### 8.1 屏幕无显示

| 检查项 | 解决方案 |
|--------|----------|
| 电源 | 确认 VCC 接 3.3V，不是 5V |
| 接线 | 检查 MOSI/SCLK/DC/CS 是否接对 |
| SPI 初始化 | 确认 `SPI.begin()` 参数顺序正确 |
| RST 引脚 | 尝试手动拉低 RST 100ms 后拉高 |

### 8.2 显示全黑/全白

```cpp
// 可能是初始化顺序问题，确保：
SPI.end();          // 先结束可能存在的 SPI
SPI.begin(...);     // 再重新初始化
display.init(...);  // 最后初始化屏幕
```

### 8.3 局刷有严重残影

```cpp
// 定期执行全刷清除残影
static int refreshCount = 0;
refreshCount++;
if (refreshCount >= 100) {
    display.setFullWindow();
    display.firstPage();
    do {
        display.fillScreen(GxEPD_WHITE);
    } while (display.nextPage());
    refreshCount = 0;
    delay(500);  // 全刷后等待稳定
}
```

### 8.4 刷新速度慢

1. **减少延时**：使用 20ms 而非 200ms
2. **缩小区域**：局刷区域越小越快
3. **检查温度**：确保环境温度 > 10°C

### 8.5 程序死机/屏幕卡住

```cpp
// 原因：指令堆积，屏幕未完成上次刷新就收到新指令
// 解决：确保 nextPage() 返回后再继续

display.firstPage();
do {
    // 绘制内容
} while (display.nextPage());

delay(20);  // 必须！等待电压稳定
```

## 附录：完整示例代码

```cpp
#include <Arduino.h>
#include <SPI.h>
#include <GxEPD2_BW.h>
#include <Adafruit_GFX.h>

// 引脚定义
#define PIN_MOSI      5
#define PIN_SCK       6
#define PIN_CS        7
#define PIN_DC        17
#define PIN_RST       18
#define PIN_BUSY      8
#define PIN_POWER_EN  47

// 显示对象
GxEPD2_BW<GxEPD2_213_B72, GxEPD2_213_B72::HEIGHT> display(
    GxEPD2_213_B72(PIN_CS, PIN_DC, PIN_RST, PIN_BUSY)
);

void setup() {
    // 电源初始化
    pinMode(PIN_POWER_EN, OUTPUT);
    digitalWrite(PIN_POWER_EN, HIGH);
    delay(100);

    Serial.begin(115200);
    Serial.println("EPD Demo Start");

    // SPI 初始化
    SPI.end();
    SPI.begin(PIN_SCK, -1, PIN_MOSI, PIN_CS);

    // 屏幕初始化
    display.init(115200, true, 2, false);
    display.setRotation(1);

    // 全刷清屏
    display.setFullWindow();
    display.firstPage();
    do {
        display.fillScreen(GxEPD_WHITE);
    } while (display.nextPage());
    delay(500);

    // 极速局刷演示
    display.setTextSize(4);
    int x = 80, y = 40, w = 60, h = 50;
    display.setPartialWindow(x, y, w, h);

    for (int i = 0; i < 10; i++) {
        // 闪白
        display.firstPage();
        do {
            display.fillScreen(GxEPD_WHITE);
        } while (display.nextPage());
        delay(20);

        // 写入
        display.firstPage();
        do {
            display.fillScreen(GxEPD_WHITE);
            display.drawRect(x, y, w, h, GxEPD_BLACK);
            display.setCursor(x + 15, y + 10);
            display.setTextColor(GxEPD_BLACK);
            display.print(i);
        } while (display.nextPage());
        delay(20);
    }

    display.hibernate();
    Serial.println("Done!");
}

void loop() {}
```
