# 字体转换工具使用说明

## 🎯 功能特性

✅ **基线对齐** - 使用字体 ascent/descent 信息，确保所有字符在同一基线上
✅ **自动读取 txt 字库** - 支持从多个 txt 文件加载字符集
✅ **智能合并去重** - 自动合并多个字库并去除重复字符
✅ **调试预览图** - 生成放大的预览图像，方便检查对齐效果
✅ **详细日志** - 显示转换进度和统计信息

## 🚀 快速开始

### 1. 配置字库文件

编辑 `convert_font.py` 的配置区：

```python
# 字库文件列表（相对于脚本的路径）
CHARSET_FILES = [
    "../ttf/常用字/level-1.txt",  # 一级常用字（约 3500 字）
    "../ttf/常用字/level-2.txt",  # 二级常用字（约 3000 字）
    # "../ttf/常用字/level-3.txt",  # 三级常用字（生僻字）
]
```

**提示**：
- 注释掉不需要的字库文件（用 `#` 开头）
- level-1 包含最常用的 3500 字，适合大多数场景
- level-2 增加 3000 个次常用字
- level-3 包含生僻字，一般不需要

### 2. 添加自定义字符

如果需要额外的字符（如 UI 专用词汇），可以在 `EXTRA_CHARS` 中添加：

```python
EXTRA_CHARS = [
    "设", "置", "系", "统", "配", "网", "固", "件", "信", "息",
    # ... 添加你需要的字符
]
```

### 3. 运行转换

```bash
cd infinity-tag-esp32/tools
python convert_font.py
```

### 4. 查看输出

- **字体头文件**: `../include/Fonts/HuiwenFangsong.h`
- **调试预览图**: `debug/` 目录（每个字符一个 PNG 文件）

## ⚙️ 技术原理

### 基线对齐算法

```
1. 获取字体度量信息（ascent, descent）
   - ascent: 基线到字体顶部的距离
   - descent: 基线到字体底部的距离

2. 测量每个字符的实际边界框（bbox）
   - left, top, right, bottom

3. 计算对齐偏移
   - 水平居中: offset_x = (font_size - char_width) / 2
   - 垂直对齐: offset_y = ascent - bbox.top

4. 在统一画布上绘制字符
   - 所有字符的基线位置一致
```

### 位图编码

- 每个字符: 12x12 像素 = 144 位 = 18 字节
- 按行扫描，每 8 个像素打包为 1 字节
- MSB (最高位) 对应最左侧像素

## 🔍 常见问题

### Q: 转换后字符仍然不对齐？

A: 检查以下几点：
1. 确认使用的是新版脚本（包含 `char_to_bitmap_baseline_aligned` 函数）
2. 查看 `debug/` 目录的预览图，确认转换正确
3. 检查 ESP32 端的渲染代码是否正确使用位图数据

### Q: 字库文件路径找不到？

A: 路径是相对于脚本所在目录的，确保：
```
infinity-tag-esp32/
├── tools/
│   └── convert_font.py  ← 脚本位置
└── ttf/
    └── 常用字/
        ├── level-1.txt
        ├── level-2.txt
        └── level-3.txt
```

### Q: 转换速度太慢？

A: 设置 `GENERATE_DEBUG_IMAGES = False` 和 `VERBOSE = False`

### Q: 内存不足？

A: 减少字符数量，只使用 level-1 字库（3500 字）
